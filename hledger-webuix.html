Lossless editing

Journal editor

Edit the original journal syntax directly. Changes remain an unsaved draft until you click Save; hledger validates before and after writing.

No journal loaded
Git commits are separate from Save. This editor edits one year only and keeps comments, directives and formatting as written. Other processes must not write to the same file at the same time.

Draft a transaction

Adds an entry to the editor without touching the disk. Use the complete hledger amount syntax (e.g. 450 CZK or -20 EUR). Leave one amount blank for automatic balancing by hledger.
